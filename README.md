# AI Chinese · 四角色课堂管理演示

新版课堂管理演示，包含学生、教师、教学管理、学校教务四个工作区。项目入口为 `/admin/`，根路径会自动跳转到后台登录页。

## 运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/admin/`。

生产构建与测试：

```bash
npm test
npm run build
npm run preview
```

## 当前范围

### 学生端

- 查看首页学习提醒、我的课表和课程日历。
- 完成课前准备、课中互动与课后复习。
- 查看课堂表现、成绩统计和消息。

### 教师端

- 查看我的课表、进行中的课堂和课程结果。
- 进入课堂直播间，切换课堂课件和互动轮次，查看实时答题数据、排名与投影。
- 在课堂设计页配置课前、课中、课后内容；课中互动按轮次平铺，支持从互动库引入、编辑和保存。
- 管理材料与互动库，查看学生成绩并完成正式考核录分。

### 教学管理端

- 查看首页待办、课程日历和课次排课。
- 管理班级与学生、学校与教职工、课程目录和课节。
- 维护课次名单、改期、取消及学生档案。

### 学校教务端

- 查看本校首页、课程日历、班级与学生。
- 只读查看课堂表现和学生成绩。
- 不包含教师评价、教师排名或操作日志。

## 目录

- `admin/`：React 四角色工作台。
- `shared/`：演示数据与平台状态存储。
- `public/shared/demo-materials/`：可真实下载和预览的演示材料。
- `tests/`：Vitest 回归测试。

旧版独立 HTML 原型与题型页面已移除，当前仓库只保留新版四角色演示。
